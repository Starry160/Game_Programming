# Class Notes and Process Evidence

This folder keeps classroom notes, presentation notes, peer feedback, and short planning records from the early development process of **Knight Legend**.

These files are not final gameplay documentation. They are included as process evidence showing how the project idea, vertical slice scope, combat plan, map work, and feedback response developed during class sessions.

| File | Purpose |
|------|---------|
| `2026-05-14-presentation-notes.md` | Class attendance and group presentation plan about Unity event-driven programming. |
| `2026-05-19-class-notes.md` | Early vertical slice planning, feature sorting, and peer feedback. |
| `2026-05-22-class-notes.md` | Session goal for skeleton combat, map setup, and combat feedback improvement. |
| `2026-05-26-class-notes.md` | Session goal for death UI, treasure rewards, and game flow refinement. |
| `2026-05-28-class-notes.md` | Session goal for map expansion, enemy variety, enemy attacks, and display bug fixes. |
